# Salesforce Notification Bridge

Projeto de integração multicanal desenvolvido para demonstrar fluxos de automação e engajamento conectando o ecossistema **Salesforce** (com foco em Service Cloud) a disparos de notificações (SMS/Push).

## Sobre o Projeto
Este repositório simula uma ponte de integração (`Bridge`) onde eventos operacionais — como a atualização ou fechamento de um Caso (Case) no Service Cloud — disparam notificações automatizadas para os clientes, unindo a eficiência do atendimento com estratégias de Marketing Cloud e mensageria.

## Tecnologias Utilizadas
* **JavaScript / Node.js**: Ambiente de execução e lógica da aplicação.
* **Git & GitHub**: Controle de versão e hospedagem do código para portfólio.
* **Salesforce Ecosystem**: Simulação de eventos de Service Cloud / Marketing Cloud.
